# 現場ツール

スマホで打って、A4・1枚のPDFにする無料ツールです。登録もアプリもいりません。

- **外構仕様書メーカー**（shiyousho.html）：工種ごとに「含む／別途／なし」を選んで、見積に添える仕様書を作る
- **現場打ち合わせシート**（uchiawase.html）：業者間の打ち合わせを、地図のQRつきで記録。LINE用の文章もコピーできる

入力した内容は、使っている端末の中にだけ残ります。どこにも送られません。

## 使い方のコツ

- スマホの「ホーム画面に追加」で、アプリのように開ける。普段はアイコンから開く
- ホーム画面のアイコンは同じURLを開く入口なので、こちらで直せば次に開いた時から新しい版になる（入れ直し不要）
- 古いままに見える時は、アプリを一度閉じて開き直す（iPhoneは下から上にスワイプして止め、上にはじく）。それでも古ければ数分待つ（GitHub Pagesの反映待ち）
- iPhoneは、ホーム画面のアイコンとSafariで打ち途中の内容の保存場所が別。片方で空でも消えたわけではない
